# Portfolio Redesign Preview — v2

Total rebuild of the Driss Ouazzani Chahdi portfolio, not a recolor.

- **Macrostructure:** Bento Grid (hero as tile composition, varied-size
  work tiles, hairline services and contact rows).
- **Palette:** Purple Haze, one accent (#8B7CC7) doing all the work.
- **Type:** Space Grotesk display + Inter body, with a real type scale.
- **Motion:** GSAP entrance stagger, scroll reveals, tile hover, ticker
  count-up. Purposeful only, no bounce easing, full reduced-motion
  support, and the page stays fully visible if the animation CDN fails.
- **Design system:** see DESIGN.md for tokens, motion spec, and the
  anti-slop checks applied.

The original portfolio repo and drizoeditz.pro are untouched. Media
(videos, thumbnails, portrait) is hotlinked from the original repo so
this preview stays lightweight.

Live preview: https://drissxdxrk.github.io/portfolio-preview/
